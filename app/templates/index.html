Quick Help

Dashboard guide

Target cards

Each card is a monitored target. It shows resolved IP, quality score, DNS time, endpoint RTT/loss/jitter, path state, and service checks.

Click a card to make that target active for the charts, path view, hop table, and CSV export.

Quality score

The score is a quick 0-100 health summary. It uses endpoint RTT/loss/jitter when available, then path metrics, DNS, service checks, and path stability.

Use the reason line under the score to see the main signal affecting that target.

Recent alerts

This strip shows up to five recent alerts from the short dashboard window. It is meant for quick awareness, not long-term review.

Use Alerts to review the full log and expand alert details.

Charts

The latency chart overlays path latency, endpoint RTT, jitter, path loss, and endpoint loss when available.

The hop-count chart shows path stability. Sudden changes can indicate routing or edge-selection changes.

Path view

The horizontal path view shows the latest visible route for the selected target. Hidden or non-responding hops can be shown with the checkbox.

The hop table below gives raw hop latency, loss, jitter, ASN, org, and geography details.

Time windows and export

The Window dropdown controls charts, latest path lookup, and CSV export. Custom lets you select an exact start/end range.

Export CSV downloads the selected target and current window.

Why this helps

This dashboard is useful when standard monitoring cannot ping a target or does not explain RTT, loss, jitter, service reachability, or path changes.

For configuration, thresholds, DSCP, endpoint probes, and cleanup, use Admin.
