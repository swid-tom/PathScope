Alert Help

Reading and clearing alert history

Alert types

Alerts currently cover latency, jitter, loss, and path changes. Metrics prefer endpoint probe results and fall back to MTR effective-hop data.

Details sections

Expand an alert for measured values, thresholds, source used, and path-change before/after hops when available.

Path changes

Path-change alerts compare responsive hops from the current successful run to the prior successful run.

Main dashboard vs history

The dashboard shows only recent alerts. This page is the logged history until you clear alerts or prune data.

Clearing alerts

Clear Alerts removes logged alert events only. It does not delete probe runs, charts, paths, or target history.
